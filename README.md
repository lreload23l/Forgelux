# Forgelux

Custom app builder SaaS — build web apps, mobile tools and automations without code.

## Pages
- `/` — Landing page
- `/login` — Sign in / sign up
- `/dashboard` — Workspace overview
- `/apps` — App library
- `/builder` — Visual canvas builder
- `/automations` — Flow editor
- `/analytics` — Usage & performance
- `/team` — Members & permissions
- `/billing` — Plans & invoices
- `/settings` — Workspace settings

## Stack
- Pure HTML/CSS/JS — no framework, no build step
- Hosted on Vercel
- Shared styles in `js/theme.css`
- Shared nav/auth in `js/nav.js` and `js/auth.js`
